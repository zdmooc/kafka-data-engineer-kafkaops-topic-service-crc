# Context (mission-oriented)

This repository simulates a Data Engineer support mission on critical Kafka platforms:
- Design / configuration / optimization / troubleshooting
- MCO automation (Ansible + standard CLI)
- Topic-as-a-Service (developer-facing REST API with governance)
- Observability integration (Elastic Stack / OpenSearch)
- Documentation, runbooks, and knowledge base

The goal is to provide:
- A runnable local lab (Docker Compose)
- A reproducible ops approach (Ansible playbooks)
- A production-minded implementation baseline (security, audit, lifecycle)
