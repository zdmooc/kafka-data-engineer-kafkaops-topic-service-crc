# International collaboration (EN)

## Communication habits
- Use concise, reproducible incident updates (what/impact/ETA/next)
- Keep a single source of truth (ticket + runbook links + evidence)
- Share validated commands and screenshots (avoid "it should work")

## Operational reporting
- Weekly report template in `docs/templates/weekly-report.md`
- KPIs: incidents, MTTR, change success rate, capacity trends

## Documentation rules
- Every operational change must have:
  - reason
  - exact commands or playbook reference
  - verification steps
  - rollback plan
